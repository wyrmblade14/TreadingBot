# TreadingBot — Learning Journal

This folder tracks every experiment, backtest result, insight, and improvement we make to the bot.
The goal: build a paper trail so we can look back and understand *why* each decision was made.

## Files

| File | What it tracks |
|---|---|
| `backtest_analysis.md` | Backtest runs, results, and what we changed based on them |
| `strategy_notes.md` | How each strategy works, its strengths, weaknesses, tuning ideas |
| `ideas_and_improvements.md` | Future improvement ideas (also mirrored in memory/) |

## How to use

- After every backtest run, add a row to `backtest_analysis.md`
- When you tune a parameter, log the before/after in `strategy_notes.md`
- Any new idea → `ideas_and_improvements.md`
