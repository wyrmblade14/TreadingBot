The user is building an automated intraday trading bot for the Indian stock market (NSE) using Zerodha as their broker. They are a **beginner with limited stock market knowledge** and have explicitly asked Claude to act as an initiator/guide on trading concepts.

Key traits:
- Wants to learn as they build — explain trading concepts when introducing them
- Not familiar with terms like RSI, MACD, intraday, paper trading etc. without context
- Prefers Python
- Wants to start safely with paper trading before risking real money
- Open to recommendations on best practices
- Wants the repository kept clean and well-structured, with memory files updated when architecture or trading logic changes
- Needs beginner-friendly explanations when introducing fundamentals, catalysts, risk filters, or any live-trading concept
