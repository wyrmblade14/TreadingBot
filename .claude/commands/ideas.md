Review and discuss the TreadingBot ideas and improvements log.

Steps:
1. Read `memory/ideas_and_improvements.md` in full.
2. Present a prioritised summary grouped by:
   - **Quick wins** (Impact H or M, Effort L) — best to tackle next
   - **High value** (Impact H, Effort H or M) — worth planning for
   - **Future scope** (Impact M/L or long-term) — park for later
3. Ask the user if they want to:
   a. Discuss any specific idea in depth
   b. Start implementing one now
   c. Add a new idea they have in mind
   d. Mark any as DROPPED
4. If implementing: follow the normal development workflow (plan → build → test → update idea status to DONE).
5. After any discussion or decision, update `memory/ideas_and_improvements.md` with the new status or any new entries discovered during the conversation.
